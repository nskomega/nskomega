### Открытый Flutter-проект

**[Objectno — «Объектно»](https://github.com/nskomega/Objectno)** — приложение для ведения ремонта: фото и история работ, обмеры помещений и расчёт материалов.

- Flutter / Dart, локальная БД Sembast, HTTP API и secure storage.
- Разделение данных гостя и аккаунтов, авторизация с обновлением сессий.
- Две темы, восемь языков, unit- и widget-тесты, отдельный нативный integration test.
- Go API и экспериментальная интеграция локальной модели через MLX на Mac.

**Статус:** личный проект в разработке, пока без публикации в App Store и Google Play. Текущие возможности, проверки и ограничения описаны в [README](https://github.com/nskomega/Objectno/blob/main/README.md) и [STATUS.md](https://github.com/nskomega/Objectno/blob/main/STATUS.md).
